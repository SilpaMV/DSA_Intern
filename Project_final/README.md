
# Restaurant Rating Predictor

A Machine Learning project that predicts the success of a restaurant based on various features like location, pricing, ratings, and services. This project helps in understanding the key factors that influence restaurant performance.

## Project Overview

The goal of this project is to build a predictive model that analyzes restaurant data and determines whether a restaurant is likely to succeed or not.

It includes:

* Data preprocessing
* Feature engineering
* Model training & evaluation
* Feature importance analysis
* Website creation Using Flask

## Technology Used

* Python 🐍
* Pandas & NumPy
* Scikit-learn
* Matplotlib & Seaborn
* Jupyter Notebook
* vs code

## Features Used 

* Average cost
* Location (City, Area)
* Restaurant Type
* Price Category
* Ratings 
* Online Order Availability
* Table Booking
* Cuisine Type
* Population & Tourist Attraction Data

Feature Importance

Feature importance was analyzed to identify key factors influencing restaurant success:

Cost, Population plays a major role
Pricing strategy impacts performance
city and cusine types are critical
